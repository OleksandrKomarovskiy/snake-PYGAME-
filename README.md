# snake-PYGAME-
Класична Змійка з підступом. Збирай яблука та соковиті груші, але кожна четверта груша — це замаскована бомба з ледь помітною іскрою! Груша живе лише 12 секунд: не встиг з'їсти — зникає, а на новому місці з'являється нова. Три рівні складності, зручна пауза на Esc, керування стрілками або WASD.
